# FraudShield ML Demo

Next.js and TypeScript prototype for the approved synopsis:

Machine Learning-Based Financial Fraud Detection System for Digital Transactions

## Included modules

- Login screen
- Transaction monitoring
- Fraud prediction engine
- Risk score calculation
- Alert generation
- Fraud analytics dashboard

## Tech stack

- Next.js App Router
- React
- TypeScript
- Local sample transaction data

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`
